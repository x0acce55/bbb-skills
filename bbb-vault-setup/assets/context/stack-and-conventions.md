# Stack and conventions

Cross-project technical facts. Project-specific stack goes in the project's index note.

This file is for the things you'd otherwise re-explain. If you correct an agent about
the same thing twice, it belongs here.

Machine, OS, shell, and anything unusual about the setup. For BBB: Windows, Claude Code
running natively, Git Bash for the Bash tool.

## Languages and tooling

have a preference an agent would otherwise get wrong.

## Conventions

Formatting, naming, testing, commit style. Write them specifically enough to verify:
"2-space indentation" rather than "format properly."
