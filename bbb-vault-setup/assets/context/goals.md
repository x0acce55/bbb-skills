# Goals

Only goals that outlive individual projects. Anything scoped to one project belongs in
that project's index note instead — putting it here means paying for it in every
session including the ones where it's irrelevant.

Review this quarterly. A goals file that hasn't changed in a year is either remarkable
or unread.

## Now

What you are actually trying to do in the current stretch.

## Later

Things you've committed to but aren't working on yet. Useful because it tells an agent
what *not* to start.

## Not doing

Deliberately abandoned. Worth writing down, because otherwise you'll re-litigate it and
so will every agent that reads this vault.
